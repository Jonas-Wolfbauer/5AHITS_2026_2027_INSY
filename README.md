# INSY · 5AHITS 2026/27

Assignments for INSY (Informationssysteme) at HTL Braunau, worked on in changing teams. Each assignment has its own folder with code, tests and generated models; the documentation is published as a website:

**https://jonas-wolfbauer.github.io/5AHITS_2026_2027_INSY/**

| Folder | Assignment |
|---|---|
| [`01-neural-network/`](01-neural-network/) | Neural network from scratch in Python and C# (XOR, 7-segment decoder) |

## Website

The documentation is written in Obsidian (school vault, folder `INSY/`) and built with [Quarto](https://quarto.org). A QuickAdd command in Obsidian copies it into `site/`, renders it locally and publishes it to the branch `gh-pages` with `quarto publish gh-pages`. `site/` is generated and not versioned — edit the pages in the vault, not here.

## Working on an assignment

Clone the repo, then follow the `README.md` inside the assignment folder. Code, identifiers and comments are in English, the documentation is in German.
